# 项目理解型 HTML

项目理解型 HTML 是帮助用户理解当前项目的独立可视化材料，例如架构图、流程演示、状态机、数据流或交互草图。它属于目标项目资料，不属于共享 Skill 本体，也不属于正式教程或产品源码。

## 生成边界

1. 只有当图示或交互页面能明显帮助理解，并且用户明确同意生成时，才创建 HTML。
2. 先说明用途、预计文件名和保存位置，再等待用户的明确同意；不能把“继续”“开始做”或批准 PRD/Task 当作 HTML 授权。
3. 用户同意只授权这份理解材料，不自动授权修改产品代码、发布文档或部署服务。

## 保存位置

将实际文件保存到目标项目的 `.agent/html/<主题>.html`，并在 `.agent/INDEX.md` 的 HTML 清单中登记名称、用途和相对路径。初始化器预建的 `.agent/html/` 为空目录不代表已经批准生成材料。

优先使用单文件、无依赖的 HTML；需要外部资源时说明依赖和预览方式。不得写入密码、令牌、个人资料、生产数据或未经确认的内部信息。

## 事实边界

HTML 只用于解释和探索，不能替代源码、测试、需求/方案/设计/任务批准、验证报告或项目状态。若材料描述的事实来自仓库，先读取实际源码、配置、测试和项目工件；发现冲突时标注冲突，不用图覆盖事实。

共享 Skill 包中的模板或生成辅助资源应放在 `references/`、`scripts/` 或 `assets/`，不要把某个目标项目的 HTML 放进 `skills/project-lifecycle/`。
