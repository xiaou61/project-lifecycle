# HTML 理解产物

这个目录专门放 AI 生成的、帮助人理解项目的独立 HTML 文件，例如架构图、流程演示、状态机、数据流或交互草图。

它们是解释和探索材料，不是产品前端、VitePress 正式文档、运行时依赖，也不能替代源码、测试、需求批准或验证报告。

## 放置规则

- 文件使用能看懂主题的名字，例如 `workflow-state-map.html`、`git-attribution-demo.html`。
- 尽量做成单文件、可直接打开；需要脚本或资源时，在文件顶部说明依赖和打开方式。
- 不放密码、令牌、个人资料、生产数据或其他敏感内容。
- 正式教程页面放 `docs/`；可下载的交付文件放 `output/`；不要重复复制同一个文件。
- 保留的 HTML 新增后，在本文件的清单中补一行，方便总索引定位。

## 预览方式

简单文件可以直接双击，或在 PowerShell 中运行：

```powershell
Start-Process .\html\<文件名>.html
```

如果浏览器限制了本地资源，再从仓库根目录启动静态服务器：

```powershell
python -m http.server 8000 --directory html
```

然后打开 `http://127.0.0.1:8000/`。
